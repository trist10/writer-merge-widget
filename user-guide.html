User Guide

Writer Merge Document Tool
Generate PDF documents from Bigin records using Zoho Writer templates and save them automatically to Zoho WorkDrive.

1. Overview

Writer Merge Document Tool adds a simple document-generation workflow to Zoho Bigin. Once a Zoho Writer merge template has been configured, you can generate a PDF directly from a Bigin Pipeline record with a single click.

The generated PDF is automatically saved to Zoho WorkDrive, and the Bigin record is updated with the latest merge information.

2. Requirements

Before using the Topping, make sure you have access to:

  • Zoho Bigin;
  • Zoho Writer;
  • Zoho WorkDrive; and
  • a Zoho Writer document configured as a merge template using Bigin as its data source.
Important: The Writer template must already be configured with the Bigin fields you want to merge into the generated document.

3. Configure the Writer template

  1. Open the Zoho Writer document you want to use as your merge template.
  2. Confirm that the document is configured for merge using the required Bigin fields.
  3. Copy the full URL from your browser's address bar while the Writer document is open.
  4. In Bigin, open Writer Merge Settings.
  5. Paste the full Writer document URL into the template URL field.
  6. Save the settings.

The Topping automatically identifies the Writer document and the appropriate Zoho data centre from the URL you provide.

4. Generate a document

  1. Open the Bigin Pipeline record you want to use.
  2. Click the Writer Merge button.
  3. The Topping checks whether the record has previously been merged.
  4. If a previous merge exists, you can choose whether to open the existing document or generate a new version.
  5. The selected Writer template is merged with the Bigin record.
  6. A PDF is generated and uploaded automatically to Zoho WorkDrive.

5. Where generated PDFs are stored

Generated PDFs are stored in a folder named:

Writer Merge Documents

This folder is created automatically inside your Zoho WorkDrive My Folders area if it does not already exist.

6. File naming and regenerated documents

Each PDF is assigned a stable filename based on the Bigin record ID.

If you generate the document again for the same record, the Topping uploads the new PDF using the same filename. WorkDrive retains the updated file as the latest version rather than creating a separate duplicate file.

7. Merge tracking in Bigin

After a successful merge, the Topping stores information on the Bigin record, including:

  • the date and time of the latest Writer merge; and
  • the WorkDrive URL of the generated document.

This allows the Topping to detect whether the record has already been merged and gives you quick access to the most recently generated document.

8. Changing the Writer template

  1. Open the Writer document you want to use instead.
  2. Copy its full browser URL.
  3. Open Writer Merge Settings in Bigin.
  4. Replace the existing template URL.
  5. Save the settings.

Future merges will use the newly configured Writer template.

9. Troubleshooting

No Writer template is configured

Open Writer Merge Settings and save the full URL of the Writer merge template you want to use.

The wrong document is being generated

Check the URL currently saved in Writer Merge Settings and make sure it belongs to the correct Writer template.

Merge fields are blank or incorrect

Open the Writer template and confirm that the merge fields are mapped correctly to the Bigin data source. The Topping uses the merge configuration defined in Writer.

The merge fails when the Writer template has an active filter

If the selected Zoho Writer template has an active merge filter, the current Bigin record must match that filter's criteria. If the record is excluded by the filter, Writer may fail to generate the PDF and the Topping may display a technical error.

If this occurs, open the merge template in Zoho Writer and review the active merge filter. Either remove the filter, change its criteria, or make sure the Bigin record you are merging matches the filter before trying the Writer Merge button again.

The PDF cannot be found

Open Zoho WorkDrive and look inside My Folders → Writer Merge Documents.

The document does not update after regenerating it

WorkDrive may retain previous file versions. Open the file in WorkDrive and confirm that you are viewing the latest version.

Permission or authentication errors

Confirm that the Zoho account installing the Topping has access to Bigin, Writer and WorkDrive and that the required permissions were granted during installation.

10. Data handling

The document-generation workflow operates through Zoho Bigin, Zoho Writer and Zoho WorkDrive. Generated PDFs are stored in the user's Zoho WorkDrive account.

For more information about data handling, refer to the Writer Merge Document Tool Privacy Policy linked from the Zoho Marketplace listing.

11. Uninstalling the Topping

You can uninstall Writer Merge Document Tool from your Bigin organisation at any time.

Uninstalling the Topping does not automatically delete PDFs already stored in WorkDrive. Any generated files you no longer require should be removed separately from WorkDrive.

12. Support

If you experience an issue, use the support contact information provided on the Zoho Marketplace listing.

When requesting support, include a brief description of the problem and any relevant error message. Do not send passwords or unnecessary sensitive customer information.
