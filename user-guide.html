User Guide

Writer Merge Document Tool
Generate PDF documents from Bigin records using Zoho Writer templates and save them automatically to Zoho WorkDrive.

1. Overview

Writer Merge Document Tool adds a simple document-generation workflow to Zoho Bigin. Once a Zoho Writer merge template has been configured, you can generate a PDF directly from a Bigin Pipeline record with a single click.

Generated PDFs are saved automatically to Zoho WorkDrive. Writer Merge Document Tool uses the stored WorkDrive file to determine whether a document has already been generated for the same Bigin record.

2. Requirements and first-time setup

Before using the Topping, make sure you have access to:

  • Zoho Bigin;
  • Zoho Writer;
  • Zoho WorkDrive; and
  • a Zoho Writer document configured as a merge template using Bigin as its data source.
Before using Writer Merge Document Tool: Authorise the Bigin, Zoho Writer and WorkDrive connections for the Topping, then configure your Writer merge template in Writer Merge Settings.
Important: The Writer template must already be configured with the Bigin fields you want to merge into the generated document.

3. Configure the Writer template

  1. Open the Zoho Writer document you want to use as your merge template.
  2. Confirm that the document is configured for merge using Bigin as its data source and contains the required merge fields.
  3. Copy the full URL from your browser's address bar while the Writer document is open.
  4. In Bigin, open Writer Merge Settings.
  5. Paste the full Writer document URL into the Writer merge template field.
  6. Click Save Settings.

The full Writer URL is required during first-time setup so the Topping can identify both the Writer document and the appropriate Zoho data centre automatically.

After the setting has been saved, Writer Merge Settings may display the Writer document ID rather than the full URL.

4. Generate a document

  1. Open the Bigin Pipeline record you want to use.
  2. Click the Writer Merge button.
  3. The Topping checks the Writer Merge Documents folder in WorkDrive for a previously generated PDF associated with that Bigin record ID.
  4. If a previous merge exists, choose View Existing to open it or Regenerate to generate the document again.
  5. If no previous merge exists, the selected Writer template is merged with the current Bigin record automatically.
  6. The generated PDF is uploaded to Zoho WorkDrive.

5. Where generated PDFs are stored

Generated PDFs are stored in a folder named:

Writer Merge Documents

This folder is created automatically inside your Zoho WorkDrive My Folders area if it does not already exist.

6. File naming and regenerated documents

Each generated PDF is assigned a stable filename based on the Bigin record ID:

Writer_Merge_<Bigin record ID>.pdf

Regenerating a document for the same Bigin record uses the same filename. This allows Writer Merge Document Tool to associate the stored WorkDrive PDF with that Bigin record without creating custom tracking fields in the Pipeline.

7. Existing merge detection

Writer Merge Document Tool detects previous merges directly from WorkDrive. When the Writer Merge button is clicked, the Topping looks in the Writer Merge Documents folder for the filename associated with the current Bigin record ID.

If the file is found, the Topping uses WorkDrive file information such as its permalink and modified time to provide the View Existing and Regenerate options.

Writer Merge Document Tool does not require custom Bigin Pipeline fields to store the last merge date or document URL.

Important: If a generated PDF is manually renamed, moved out of the Writer Merge Documents folder, or deleted, Writer Merge Document Tool may no longer recognise it as the previous merge for that Bigin record.

8. Changing the Writer template

  1. Open the Writer document you want to use instead.
  2. Copy its full browser URL.
  3. Open Writer Merge Settings in Bigin.
  4. Replace the current value with the new Writer document URL.
  5. Click Save Settings.

Future merges and regenerations will use the newly configured Writer template.

Changing the configured template does not alter a PDF that has already been generated. If you choose View Existing, the existing WorkDrive file will open. Choose Regenerate if you want to create a new version using the newly configured template.

9. Troubleshooting

No Writer template is configured

Open Writer Merge Settings and save the full URL of the Writer merge template you want to use.

The wrong document is being generated

Check the template currently saved in Writer Merge Settings and make sure it belongs to the correct Writer document. If an older PDF already exists for the record, View Existing opens that stored file; use Regenerate to create a new version using the currently configured template.

Merge fields are blank or incorrect

Open the Writer template and confirm that the merge fields are mapped correctly to the Bigin data source. The Topping uses the merge configuration defined in Writer.

The merge fails when the Writer template has an active filter

If the selected Zoho Writer template has an active merge filter, the current Bigin record must match that filter's criteria. If the record is excluded by the filter, Writer may fail to generate the PDF and the Topping may display a technical error.

If this occurs, open the merge template in Zoho Writer and review the active merge filter. Either remove the filter, change its criteria, or make sure the Bigin record you are merging matches the filter before trying the Writer Merge button again.

View Existing / Regenerate does not appear for a record that was previously merged

Open Zoho WorkDrive and check My Folders → Writer Merge Documents. The generated file must remain in that folder with its original Writer_Merge_<Bigin record ID>.pdf filename for the Topping to identify it automatically.

The PDF cannot be found

Open Zoho WorkDrive and look inside My Folders → Writer Merge Documents.

The document does not update after regenerating it

Open the file in WorkDrive and confirm that you are viewing the latest version of the document.

Permission or authentication errors

Confirm that the Zoho account installing the Topping has access to Bigin, Writer and WorkDrive and that the required connections have been authorised for the Topping.

10. Data handling

The document-generation workflow operates through Zoho Bigin, Zoho Writer and Zoho WorkDrive. Generated PDFs are stored in the user's own Zoho WorkDrive account.

Writer Merge Document Tool uses the Bigin record ID to perform the merge and reads WorkDrive file metadata, including the generated filename, permalink and modified time, to identify existing merges.

The Topping stores the configured Writer template identifier and the Zoho API domain for the user's data centre as organisation-level configuration in Bigin. It does not create custom Pipeline fields for merge tracking.

For more information about data handling, refer to the Writer Merge Document Tool Privacy Policy linked from the Zoho Marketplace listing.

11. Uninstalling the Topping

You can uninstall Writer Merge Document Tool from your Bigin organisation at any time.

Uninstalling the Topping does not automatically delete PDFs already stored in WorkDrive. Any generated files you no longer require should be removed separately from WorkDrive.
